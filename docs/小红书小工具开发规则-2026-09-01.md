# 小红书小工具开发规则 · 2026-09-01 项目执行清单

> 官方来源：<https://fe-video-qc.xhscdn.com/fe-platform-file/104101b8324ihuc967a06277180ac7t8006ptl0fm199r4.html>
>
> 本文件是项目执行清单，不替代官方页面或上传页当前 `SKILL.md`。每次新的创作、改写、兼容修复或上传打包，都必须重新取得上传页当次完整改写口令并按其当前 Skill 执行。

## A. 发布环境

- [ ] 纯 HTML / CSS / JavaScript Web 应用。
- [ ] Android 最低基线按 Android 8.1 / Chrome-WebView 61 验证。
- [ ] iOS 核心功能不依赖 iOS 独占增强。
- [ ] 所有运行时资源完全离线、随 ZIP 提供。
- [ ] 普通浏览器未注入 `window.xhs` 时，核心游戏仍可运行。

## B. JavaScript / CSS 兼容性

- [ ] 发布 JavaScript 处于 ES2017 / Chrome 61 可解析运行范围。
- [ ] `node --check` 已执行，但不把它当作 Chrome 61 证明。
- [ ] 未残留 optional chaining、nullish coalescing、class fields、BigInt、logical assignment 等高版本语法。
- [ ] CSS 在 Chrome 61 下保留基础布局；高版本属性仅作渐进增强。
- [ ] 高版本 API/CSS 使用前有 feature detection 或 fallback。
- [ ] 已检查 `inset`、CSS `min()/max()/clamp()`、flex `gap`、`env()`、`backdrop-filter`、`overscroll-behavior` 等晚于 Chrome 61 的能力是否有基础声明或安全降级。

## C. CSP / 资源加载

- [ ] 只有包内经典 `<script src>`。
- [ ] 无内联 `<script>`、行内事件、`javascript:` URI。
- [ ] 无 ES Module 运行依赖。
- [ ] 无 `eval()` / `new Function()` / WebAssembly。
- [ ] 无 HTTP(S) / CDN / 远程图片 / 远程字体 / 远程媒体 / 远程配置。
- [ ] 图片只使用包内、`data:` 或 `blob:`；使用 `data:`/`blob:` 图片时接受客户端 9.37+ 边界。
- [ ] 字体只使用包内字体。
- [ ] 无 iframe / object。
- [ ] ZIP 中只有允许扩展名，且有且只有一个入口 HTML。

## D. 禁用 Web 能力

- [ ] 无 fetch / XHR / WebSocket / EventSource / WebRTC。
- [ ] 无 geolocation / clipboard / execCommand copy-cut-paste。
- [ ] 无 Bluetooth / USB / HID / Serial。
- [ ] 无传感器 / DeviceMotion / DeviceOrientation。
- [ ] 无 Worker / SharedWorker / ServiceWorker。
- [ ] 无屏幕共享 / Fullscreen / Pointer Lock / Keyboard Lock。
- [ ] 无 Battery / Network Information / enumerateDevices。
- [ ] 无 storage.persist / 跨域存储访问。
- [ ] 无 Credentials/WebAuthn / Web Locks。
- [ ] 无 window.open / window.prompt。
- [ ] 不依赖 PaymentRequest、Notification/Push、NFC、MIDI、XR/AR/VR、后台同步/下载、PWA 或窗口管理。

## E. 禁用页面行为

- [ ] 无 `<form>` 跳转提交。
- [ ] 无 `<a download>` 或 blob 下载。
- [ ] 无 `target="_blank"`。
- [ ] 无站外导航。
- [ ] 无小工具间跳转。
- [ ] 不把长按菜单作为功能入口。

## F. WebGL / 图形计算

- [ ] WebGL 纹理来自包内资源、Canvas 或内存对象。
- [ ] 无外部纹理。
- [ ] 无依赖 WASM 的 Draco / Basis / ONNX / 图像算法路径。
- [ ] 无 OffscreenCanvas + Worker。
- [ ] 无 SharedArrayBuffer 多线程。
- [ ] `three-mesh-bvh` 未开启 `useSharedArrayBuffer:true`。

## G. 小红书端能力

当前白名单只有：

- `window.xhs.miniTool.postNote`
- `window.xhs.miniTool.saveImageToPhotosAlbum`
- `window.xhs.miniTool.writeTempFile`

发布前检查：

- [ ] 无直接 bridge `postMessage`。
- [ ] 无未列出的 `miniTool` API。
- [ ] API 参数没有表外字段。
- [ ] 调用前检查 SDK 是否存在。
- [ ] `postNote.title` ≤ 20 字。
- [ ] `postNote.content` ≤ 1000 字。
- [ ] 图片 1–18 张；媒体只用 data URI/base64 或本地路径。
- [ ] 不把 `postNote` 成功回调表述为最终审核通过。
- [ ] 相册保存由用户主动点击触发。
- [ ] `writeTempFile` 返回路径不写入持久化存储。

## H. 当前项目发布流程

1. 读取 `AGENTS.md`。
2. 读取 `orbital/PROJECT_STATE.md`、`DECISIONS.md`、`LESSONS.md`。
3. 读取 `orbital/XHS_MINITOOL_CAPABILITY_LIST.md`。
4. 从小工具上传页获取当次完整改写口令和当前 Skill。
5. 按当前 Skill 修复/打包。
6. 运行 `tests/test_xhs_rules_20260901.js`。
7. 在完整工作区存在发布清单时，再运行 `tests/test_minitool_compliance.js` 和其他全量回归。
8. 对全部发布 JavaScript 做 Chrome 61 / ES2017 兼容验证。
9. 对 CSS 做 Chrome 61 基础布局/fallback 审查。
10. 检查 ZIP 文件类型、单入口、离线引用和包体限制。
11. 最后进行真实小红书容器真机验证；现代桌面 Chrome 或模拟器通过不能替代真机结论。

## I. 历史规则处理

- 2026-08-11 版本能力清单已被 2026-09-01 版本覆盖。
- 历史 `.codex/references/`、Skill、session 或文档若与当前官方规则冲突，不得继续作为实现依据。
- 历史文档中的未列出端能力或字段只有在后续官方当前文档重新确认后才能恢复使用。
