---

### 🎮 这游戏到底有多离谱？

✅ **零门槛**：不需要 Steam，不需要下载，不需要 npm install，浏览器打开就能突突突

✅ **真·3D 画面**：Three.js 引擎加持，阴影、光照、雾效、棋盘格地面，有内味了

✅ **完整枪械系统**：
- 🔫 USP 半自动手枪（12发弹匣）
- 💥 AK-47 全自动步枪（30发弹匣）
- 弹道散布 + 后坐力 + 爆头4倍伤害 + 换弹 + 切枪，该有的全都有！

✅ **8 种命名 AI 敌人**：巡逻 / 追击 / 战斗三状态 AI，会走位绕圈、会点射、被打还会晃，真不是木桩 🤖

✅ **随机 8~12 波**：每波 3~14 人、血量 80→300、速度递增，全清即胜利，你能撑到第几波？

✅ **CS 经典对称地图**：CT 房间 / T 房间 / 中央长廊 / 木箱掩体 / 门洞，梦回 dust2

✅ **程序化音效**：枪声、命中、换弹、回合、胜利失败——全部 Web Audio API 合成，零音频文件！🎧

✅ **手机也能玩**：虚拟摇杆 + FIRE 按钮 + 触屏视角，地铁上也能来一把

✅ **完整 HUD**：准星、血条护甲、弹药、击杀提示、小地图、受击红屏，沉浸感拉满 💯

---

### 🧠 技术栈一览

> 纯 JavaScript (ES Module) × Three.js
> 8 个模块拆分，AABB 碰撞检测 + 射线胶囊体命中判定
> Pointer Events 鼠标拖动瞄准，Source 引擎风格速度积分

前端写到这个程度，我只能说：**大佬请收下我的膝盖** 🧎‍♂️
