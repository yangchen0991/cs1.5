## 📝 正文

家人们谁懂啊😭

有人用**纯 JavaScript**，在浏览器里手搓了一个 CS 1.5 射击游戏！

**双击 index.html 就能玩**，零依赖、零服务器、零下载，离线 zip 都能跑 🔥

---

### 🎮 这游戏到底有多离谱？

✅ **零门槛**：不需要 Steam，不需要 npm install，双击即战，点开就突突突

✅ **真·3D 画面**：Three.js 渲染，阴影、光照、雾效、棋盘格地面，梦回 dust2

✅ **2 把真实枪械**：USP 半自动手枪（12 发弹匣）+ AK-47 全自动步枪（30 发弹匣），**爆头 4 倍伤害**、腿部 0.75 倍、弹道散布、后坐力上跳、枪口火光、墙面弹孔，该有的全都有 🔫

✅ **8 个代号敌人**：Phantom / Viper / Ghost / Reaper / Fang / Echo / Talon / Raven，名字很酷，但**共享同一套 AI 状态机**，真不是 8 种行为 🤖

✅ **聪明的敌人 AI**：idle 巡逻 → **0.35 秒反应期** → engage 战斗；远距追击、中距绕圈走位、近距后撤、**三连点点射**、被卡墙 1 秒自动反转脱困、还会利用掩体遮挡视线！12% 概率爆头，伤害 ×3，会躲会打真不呆

✅ **随机 8~12 波递增难度**：每波 3~14 人（封顶）、血量 80→300（封顶）、速度越来越快，**后期就是 BOSS 波**，你能撑到几波？

✅ **CS 风格对称地图**：CT 房 / T 房 / 中央长廊 / 4 个门洞 / 木箱掩体（全高、半高、胸墙），有内味了

✅ **完整 HUD**：**准星间隙随移动动态张开收拢**、血条护甲、弹药数、击杀提示，还有**左上小地图**——敌人红点、血包绿块、墙体灰块全能看到 🗺️

✅ **4 个医疗包**：白红十字箱 + 红色光晕，拾取 +50 HP，**满血不消耗**（留着应急），15 秒重生

✅ **程序化音效**：枪声、命中爆头、换弹、回合、胜利失败——全部 Web Audio API 合成，**零音频文件** 🎧

✅ **手机也能玩**：虚拟 D-pad + FIRE 按钮 + **多指独立视角**（视角拖拽不挡开火），竖屏自动切 88° FOV 补偿，地铁上单手也能来一把 📱

✅ **性能彩蛋**：弹道/弹孔对象池复用、移动端阴影降级、HUD 脏检查、敌人视线检测节流——前端细节控狂喜 💯

---

### 🧠 技术栈一览

> 纯 JavaScript（经典脚本，全部挂到 window）× Three.js × Web Audio API
> 9 个模块：config → three → map → player → enemy → weapon → hud → audio → pickup → main
> AABB 碰撞检测 + 射线命中判定，Source 引擎风格速度积分
> 敌人视线检测每帧遍历 30+ AABB，节流到 0.12s

前端写到这个程度，我只能说：**大佬请收下我的膝盖** 🧎‍♂️
