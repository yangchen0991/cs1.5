## 三、正文（980 字）

家人们谁懂啊😭

有人用纯前端技术，在浏览器里手搓了一个 CS 风格的 3D 射击游戏——**双击 index.html 就能玩**，零依赖、零服务器、零下载，离线 zip 都能跑 🔥

这个项目我叫它 **「指尖CS」**，一把专为小红书生态打磨的浏览器 FPS 小工具。

---

### 🎮 这游戏到底有多离谱？

✅ **零门槛**：不需要 Steam，不需要 npm install，不需要下载，浏览器点开就突突突

✅ **三把真实枪模**（这次真的下血本了）：

- 🔫 **Glock-18**：赛博霓虹程序化建模，金属质感拉满
- 💥 **AK-47**：真实 OBJ 模型内嵌，32,900 顶点 + 4 通道 PBR 贴图
- 🎯 **AWP**：真实 OBJ 模型内嵌，37,500 顶点（原始 150 万面减到 7.5 万），蓝镜片、双脚架、红弹匣

✅ **弹壳系统**：开枪后黄铜弹壳从抛壳口真实弹出，重力下落 + 自旋 + 落地弹跳，1 秒后回收——不是特效，是物理 🔫

✅ **后坐力三档差异化**：USP 轻快、AK 连发左右摆、AWP 沉重后坐慢回位。AWP 后缩 22.6cm、上挑 9.7°，开一枪整个屏幕都在抖

✅ **枪口焰升级**：火焰锥 + 高亮内芯，加法发光混合，火焰长度随机——再也不是半透明小球了

✅ **换弹四段动画**：卸夹 → 脱出 → 插夹 → 回位。弹夹真的从枪上滑出来、甩出去、新夹再插回去，不是简单的枪身晃一下

✅ **8 个代号 AI 敌人**：Phantom / Viper / Ghost / Reaper / Fang / Echo / Talon / Raven，共享一套状态机，但走位、点射、卡墙脱困、利用掩体全都会

✅ **随机 8~12 波递增**：每波 3~14 人，血量 80→300，速度越来越快，后期就是 BOSS 波，你能撑到第几波？

✅ **CS 风格对称地图**：CT 房 / T 房 / 中央长廊 / 木箱掩体，梦回 dust2

✅ **完整 HUD**：准星随移动动态张开收拢、血条护甲、弹药数、击杀提示、左上小地图——敌人红点、血包绿块全能看到 🗺️

✅ **4 个医疗包**：白红十字箱 + 红色光晕，拾取 +50 HP，满血不消耗（留着应急），15 秒重生

✅ **程序化音效**：枪声、命中爆头、换弹、回合、胜利失败——全部 Web Audio API 合成，零音频文件 🎧

✅ **手机也能玩**：虚拟 D-pad + FIRE 按钮 + 多指独立视角（视角拖拽不挡开火），竖屏自动切 88° FOV 补偿，地铁上单手也能来一把 📱

✅ **性能彩蛋**：弹道/弹孔对象池复用、弹壳池化 12 个 + 物理积分、移动端阴影降级、HUD 脏检查、敌人视线检测节流——前端细节控狂喜 💯

---

### 🧠 技术栈一览

> 纯 JavaScript × Three.js r160 × Web Audio API
> 20 个模块平铺：config → three → map → player → enemy → weapon → hud → audio → pickup → main
> AABB 碰撞检测 + 射线三角级命中判定，Source 引擎风格速度积分
> 三把枪全部真实模型化，PBR 贴图 1024px webp base64 内嵌（零外部依赖）
> 敌人视线检测每帧遍历 30+ AABB，节流到 0.12s

前端写到这个程度，我只能说：**大佬请收下我的膝盖** 🧎‍♂️
