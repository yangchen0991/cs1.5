### 🎮 这游戏到底有多离谱？

✅ **零门槛**：不需要 Steam，不需要 npm install，双击即战，点开就突突突

✅ **真·3D 画面**：Three.js 渲染，阴影、光照、棋盘格地面，梦回 dust2

✅ **3 把真实枪械**，单按钮「换」循环切枪：

- 🔫 **USP 半自动手枪** — 伤害 24，爆头 4 倍（96），弹匣 12，射速 0.16s，10m 满伤 → 50m 衰到 50%
- 🔫 **AK-47 全自动步枪** — 伤害 30，爆头 120 **可秒杀**，弹匣 30，约 10 发/秒，需压枪，越打越散
- 🔫 **AWP 栓动狙击枪** — 伤害 100，爆头 150，弹匣 5，**FOV 45° 开镜**（默认 75°），圆形镜筒 + 十字线 + 边缘暗角，500m 射程，300m 仍保 70% 伤害，几乎零散布 🎯

✅ **8 个代号敌人**：Phantom / Viper / Ghost / Reaper / Fang / Echo / Talon / Raven — 名字很酷，但**共享同一套 AI 状态机**，真不是 8 种行为 🤖

✅ **聪明的敌人 AI**：视野检测 + 追击/横移走位 + **三连点点射**，反应时间 0.35s；被卡墙 1 秒自动反转脱困，还会利用掩体遮挡视线

✅ **随机 8~12 波**（不是固定 5 波！）：每波敌人数基准 3 人、每波递增 1.4 倍 ±2 浮动；血量 80 → 每波 +30；速度 2.8 → 每波 +0.35，封顶 4.8（你走速 7.5，超 6.2 就追不上了）—— 全清即胜利，血量归零即失败

✅ **CS 风格对称地图**：CT 房 / T 房 / 中央长廊 / 木箱掩体，AABB 碰撞 + 射线命中，有内味了

✅ **完整 HUD**：准星随移动/散布动态张开收拢、血条护甲、弹药数、击杀提示流（含武器名/爆头标识），还有**左上小地图**——敌人红点 / 血包绿块 / 弹药包琥珀色 / 墙体灰块 🗺️

✅ **补给 + 护盾**：4 个血包（+50 HP）+ 4 个弹药包（+2 弹匣），15 秒重生，满状态不消耗；敌人 **18% 概率掉落护甲**（军绿防弹板 + 蓝色光晕），拾取 +50 护盾点数，护甲吸收 50% 伤害

✅ **程序化音效**：枪声、命中、爆头、击杀、受伤、换弹、切枪、通关——全部 Web Audio API 合成，**零音频文件** 🎧

---

### 📱 移动端这次真的用心了（重点！）

- 横屏：Android 全屏 + 方向锁定，iOS/WebView 用 CSS 整页旋转兜底
- 左半屏浮动摇杆（任意处按下出现，拖动控制移动）
- 右半屏滑动视角
- **FIRE 按钮：按住连发 / 轻点单发**
- **按住 FIRE 拖动也能转视角** —— 三指可同时操作：摇杆 + 开火 + 视角，真机流畅化 🤯
- 跳 / 蹲 / 换弹 / 暂停 / 设置按钮齐全
- **单按钮「换」循环切枪**（替代旧版 3 个编号按钮，避免遮挡屏幕）
- **AWP 独立「镜」按钮** —— 仅狙击枪生效，其他枪无操作，点按切换开镜/关镜
- 按钮大小可调（70%~140%），**自定义按钮布局**：拖动到顺手位置，localStorage 持久化，可恢复默认

### 💥 视觉 + 听觉反馈，细节控狂喜

- 命中标记 X（白 / 爆头金放大 / 击杀更大更久）+ 伤害飘字（-24 / -96，爆头金色放大，650ms 上浮淡出）
- 准星随移动/散布动态张开收拢，受击红屏
- 弹道轨迹、枪口火光、弹孔贴墙、击杀提示流
- 弹药告警三态：≤25% 黄 / =0 红闪

---

### 🧠 技术栈一览

> 纯 JavaScript（经典脚本，全部挂到 window）× Three.js × Web Audio API
> **10 个模块**：config → three → map → player → enemy → textures → weapon → hud → audio → pickup → main
> AABB 碰撞 + 射线命中判定（三角级求交，按部位标签分类），Source 风格速度积分
> 敌人视线检测节流到 0.12s，HUD 脏检查，移动端阴影降级 1024

前端写到这个程度，我只能说：**大佬请收下我的膝盖** 🧎‍♂️
