## 1. 产品目标

> 一句话：把现有"能打中"的武器系统升级为"**打得准、打得爽、看得清**"的 CS 级手感——命中判定精确、反馈可读、武器手感差异化、视觉音效反馈完整闭环。

现状基线（代码检查结论）：
- 已有：三角级精确命中（head/torso/arm/leg/gun）、部位倍率（head 4x / leg 0.75x / arm 1x / gun 0.5x）、墙遮挡 + 弹孔贴墙法线、后坐力、移动散布、换弹（R）、切枪（1/2）、第一人称枪模、弹道轨迹、血花/爆头火花、枪口火光、准星扩散。
- 缺口：命中/爆头/击杀反馈弱（仅准星闪红）、切枪无动画、空仓提示弱、伤害无距离衰减、无穿墙、无换弹音效接入、两把武器枪模几乎相同、自动武器无连发散布累积、HUD 存在若干小缺陷（见 P0）。

## 3. 需求池

### 3.1 P0（必做：缺陷修复 + 核心体验）

#### 3.1.1 全面检查发现的高优先级缺陷修复

| # | 缺陷描述 | 位置 | 验收标准 |
| --- | --- | --- | --- |
| D1 | 换弹音效未接入：`AudioFX.reload()` 已实现但 `WeaponSystem.startReload()` 从未调用，换弹全程无声 | weapon.js L94-101 / audio.js L118 | 按 R 换弹即播放换弹音（双咔哒） |
| D2 | 空仓反馈弱：弹匣空时仅 toast 文字，无空仓"咔嗒"音、弹药数字无红色告警 | weapon.js L160-167 / hud.js | 空仓时播放咔嗒音 + 弹药数字红色闪烁 + 提示"按 R 换弹" |
| D3 | `HUD.crosshairFire()` 为空实现：射击时准星无扩张/变色反馈（与 hitMarker 的 flash 混在一起） | hud.js L86-88 | 每次射击准星短暂扩张 + 变色（区别于命中标记） |
| D4 | 初始 HTML 弹药显示不一致：index.html 中 USP 备弹写死 36，config 实际 60 | index.html L70 | 开局后弹药显示与 config 一致（60） |
| D5 | 低弹量无预警：弹匣 ≤25% 时无视觉预警，玩家常打到空仓才反应 | hud.js updateWeapon | 低弹量弹药数字变黄，空仓变红闪烁 |

#### 3.1.2 命中反馈 HUD 增强

| # | 需求 | 说明 | 验收标准 |
| --- | --- | --- | --- |
| F1 | 命中标记（Hit Marker） | 命中敌人时，准星旁出现 X 形标记，短暂浮现（约 150ms），白色 | 命中即出现，未命中不出现 |
| F2 | 爆头标记 | 命中头部时标记放大变亮、金色，与躯干/四肢命中明显区分 | 爆头标记样式与普通命中不同 |
| F3 | 击杀确认标记 | 击杀时标记醒目放大 + killFeed 强化（显示武器名/爆头标识） | 击杀反馈与普通命中显著不同 |
| F4 | 部位命中音效区分 | 爆头音（高亮"叮"）、普通命中音、击杀音分离 | audio.hit(head) 已区分，补充击杀音 |

#### 3.1.3 武器切换动画

| # | 需求 | 说明 | 验收标准 |
| --- | --- | --- | --- |
| F5 | 切枪动画 | 切枪时枪模先下放（holster）→ 上抬（draw）动画，约 0.3s，与切枪冷却同步 | 切枪不再瞬间换模，有明显抽/放动作 |

### 3.2 P1（应做：武器差异化）

| # | 需求 | 说明 |
| --- | --- | --- |
| S1 | 连发散布累积/恢复 | AK 连发时散布随连续射击累积扩张，停止射击后快速恢复；USP 散布基本恒定。准星扩张与散布严格一致（现仅移动因子） |
| S2 | 后坐力模式差异化 | AK 竖向上扬为主 + 随机左右摆动（类 CS 压枪节奏）；USP 轻微上抬。两把武器压枪手感明显不同 |

| S4 | 音效增强 | 换弹接入（D1）、空仓音、弹匣抽出/插入分段音、墙击中音（木箱 vs 混凝土区分）、爆头/击杀音（F4） |
| S5 | 枪模视觉升级 | USP/AK 两套独立枪模（长度/配色/弹匣位置区分明显），不再共用盒子组合；枪口火光大小/颜色区分（USP 小、AK 大） |
