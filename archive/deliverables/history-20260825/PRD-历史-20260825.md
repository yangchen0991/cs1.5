## 1. 项目概述

### 1.1 一句话描述

一个用纯 JavaScript + Three.js 在浏览器中实现的 CS 1.5 风格第一人称射击游戏，零依赖、零服务器、双击 `index.html` 即可游玩，以离线 zip 形态在小红书小工具容器中发布。

### 1.2 产品背景

- 以经典 CS 1.5（Counter-Strike 1.5）为核心体验参照，还原第一人称射击的核心操作感：移动、瞄准、射击、换弹、切枪、后坐力控制。
- 选择"浏览器手搓"作为产品差异点：不需要 Steam、不需要 npm install、不需要下载，打开网页就能突突突，形成"前端大佬手搓 3D 射击"的传播话题。
- 配合小红书平台的小工具容器能力（离线 H5 + zip 包），以低成本获客，形成"技术展示 + 情怀共鸣"的内容传播闭环。

### 1.3 产品现状

截至本文档编写时，项目已完成：

- **视觉全面重构**：冷峻军事基调（阶段 1 ✅）
- **武器精细化**（阶段 2）：当前实现为 Glock-18 程序化模型，AK-47 与 AWP 使用内嵌 OBJ 和离线 PBR 贴图；三枪并非全部真实模型化
- **手感三件套**：弹壳系统 + viewKick 后坐力 + 枪口焰
- **换弹四段复合动画**：卸夹 → 脱出 → 插夹 → 回位
- **正式发布基线** `cs1.5-minitool.zip`（6,781,624 B / MD5 6cd23278cafbd369c38e1ae3844f3f4d / 20 文件）继续独立保留；当前审核候选为 `cs1.5-minitool-hybrid-rig-audit.zip`（24 文件 / 约 5.69 MB）

**当前进入阶段：** 阶段 3 地图主题化 / 阶段 4 敌人·HUD·特效。

## 4. 核心功能

### 4.1 玩法循环

```
开始菜单 → 点击开始 → 随机生成 8~12 关 → 每关刷 N 名敌人 →
消灭全部敌人 → 下一关 → 通关（胜利）/ 阵亡（结算）
```

**单局结构：**
- 总波次数：随机 8~12 波
- 每波敌人数量：3→14 人（随波次递增，封顶 14）
- 敌人血量：80→300 HP（随波次递增，封顶 300）
- 敌人速度：2.8→4.8 m/s（随波次递增，封顶 4.8）
- 后期分层强化：进度 >45% → 精英 tier 1，>75% → 王牌 tier 2

### 4.2 武器系统

| 武器 | 类型 | 伤害 | 弹匣 | 备弹 | 射速 | 特点 |
|------|------|------|------|------|------|------|
| **Glock-18**（slot 1） | 半自动 | 30（头×4） | 20 | 120 | 0.15s | 赛博霓虹外观，初始武器 |
| **AK-47**（slot 2） | 全自动 | 30（头×4） | 30 | 90 | 0.099s | 真实 OBJ 模型 + PBR 贴图，后坐力重 |
| **AWP**（slot 3） | 栓动单发 | 100（头×1.5） | 5 | 20 | 0.85s | 狙击步枪，开镜 FOV 45°，移速 -25% |

**模型分工与接口：** Glock-18 由 `weapon.js` 的 `_buildGlock()` 程序化构建；AK-47 与 AWP 是各自文件内嵌的 OBJ。两类 OBJ 模块的真实接口均为 `build(geometry, material)`，武器系统实际以 `build(null, material)` 调用；不能把三把枪都描述为真实模型。

**通用机制：**
- 部位伤害倍率：头 ×4 / 躯干 ×1 / 腿 ×0.75 / 枪 ×0.5
- 穿甲 47%（Glock）
- 距离衰减：近程满伤 → 远程按 falloffMin 倍率衰减
- 连发散布累积（AK 每发 +0.004，USP 不累积）
- 弹药告警三态：满 / ≤25% 黄 / =0 红闪
- 空仓自动换弹（autoReload）

### 4.3 敌人 AI

**状态机：** `idle`（巡逻）→ `react`（0.35s 反应期）→ `engage`（战斗）

**行为策略：**
- 远距（>18m）：接近，速度 ×1.3
- 中距（6~18m）：横向绕圈走位 + 偶尔逼近
- 近距（<6m）：普通敌人后撤；精英/王牌不后撤，压近输出
- 精英/王牌专属：**冲刺突进**（每 3~6s 一次，速度 ×2.2，持续 0.8s）+ **近战重击**（精英 16 伤 / 王牌 24 伤）
- 点射：3 发一组，精英 +2 发，王牌 +3 发
- 视线检测：0.12s 节流，2D 线段判定优先 + raycast 兜底
- 卡墙解困：累计 1s 无位移 → 采样 8 方向朝最开阔方向逃离
- AI-AI 防穿模：10Hz 节流，最小间距 0.9m

**命中判定：** 12% 概率爆头（伤害 ×3），命中部位按网格 userData 精确分类。

### 4.4 地图

**CS 风格对称竞技场**（64×40 米）：

- **CT 房**（左侧 x≈-14）/ **T 房**（右侧 x≈14）
- **中央长廊**（z∈[-4,4]），两侧隔墙带门洞
- **外围墙**（高 5m）+ **房间间隔墙**
- **掩体箱**：9 个（中央长廊 3 + 上下区域 6），全高/半高/胸墙三种
- **玩家出生点**：(-22, 0, 0)；**敌人出生点**：6 个固定点 + 随机采样（避开玩家 14m）

### 4.5 补给系统

| 类型 | 外观 | 数量 | 效果 | 重生 |
|------|------|------|------|------|
| **血包** | 白底医疗箱 + 红十字 + 红色光晕 | 4 个固定点 | +50 HP | 15s |
| **弹药包** | 军绿弹药箱 + 3 枚弹头 + 琥珀光晕 | 4 个固定点 | USP+24 / AK+60 / AWP+10 | 15s |
| **护甲**（敌人掉落） | 军绿防弹背心板 + 蓝色护盾光晕 | 18% 掉落概率 | +50 护盾 | 不重生（新局清理） |

**核心规则：** 满血/满弹/满盾时不消耗，补给保留在场上。

### 4.6 视觉反馈系统

- **命中标记三态：** 普通命中（白 X）/ 爆头（金色放大）/ 击杀（红色双线更大更久）
- **伤害飘字：** DOM 池复用，命中点投影显示 -24/-96，爆头金色放大，650ms 上浮淡出
- **准星扩散：** 静止收拢、移动张开 + 连发累积（所见即所射）
- **受击红屏：** 300ms 红色边缘淡出
- **弹道轨迹：** 池化复用，60ms 淡出
- **弹孔：** 沿墙面法线精确贴合，6s 淡出
- **着弹点火花：** 命中敌人精确点闪出血花/爆头火花
- **枪口焰：** 火焰锥 + AdditiveBlending 内芯，60ms 衰减
- **弹壳系统：** 池化 12 个黄铜弹壳，重力积分 + 自旋 + 落地弹跳一次 + 1.2s 停留回收
- **AWP 瞄准镜：** 圆形镜筒 + 十字线 + 外围暗角 + FOV 45° 平滑过渡

### 4.7 听觉反馈

**全部程序化合成（Web Audio API），零音频文件：**

| 音效 | 合成方式 |
|------|---------|
| 枪声 | 白噪声 burst + 低频 thump（AK 低沉 / USP 清脆） |
| 命中/爆头/击杀 | 短促方波 + 击杀上行琶音 |
| 换弹 | 三次咔哒音 |
| 切枪 | 噪声 burst + thump |
| 受伤 | 噪声 + 低频 thump |
| 回合开始 | 上行三音 |
| 胜利/失败 | 四音琶音（胜上行 / 败下行锯齿波） |

**3D 空间音频：** 敌人开枪按世界坐标 PositionalAudio 池播放（6 个池，refDistance 8m，rolloff 1.2），不可用时回退全局播放。

### 4.8 操作与控制

**PC 端：**
- WASD 移动 / 鼠标视角 / 左键射击 / R 换弹 / 1/2/3 切枪 / Shift 蹲伏 / Ctrl 蹲伏 / Space 跳 / Esc 暂停 / C 开镜（AWP）

**移动端：**
- 虚拟摇杆（左半屏三角洲式，按下出现，拖动模拟量）
- 动作键簇（右下角）：FIRE（按住持续射击 + 拖动转视角）、跳、蹲、换弹、武器循环
- AWP 开镜/关镜按钮（右缘中部）
- 多指独立视角（视角拖拽不挡开火）
- 竖屏自动强制横屏（整页旋转 90°）+ 88° FOV 补偿

**辅助功能：**
- 设置中心：按钮大小滑块（70%~140%）+ 转身灵敏度（70%~150%）+ 自定义控件布局（拖拽保存到 localStorage）
- 布局编辑模式：拖动按钮到顺手位置
- 自诊断条（URL `?debug=1`）：视口尺寸/缩放/旋转状态
- 错误捕获浮层：任何运行时报错显示红字，便于真机排查

### 5.3 关键技术决策

**命中判定：三角级 Raycaster**
- 用 THREE.Raycaster 对敌人真实网格做三角级求交
- 每个网格打 `userData.part`（head/torso/arm/leg/gun）和 `userData.enemy` 标签
- intersectObjects 已按距离升序排序，取 [0] 即最近命中
- 命中发生在 render 前，需对目标 mesh 调 `updateMatrixWorld(true)` 强制刷新

**碰撞：圆-AABB + 最浅穿透轴推出**
- `Box.resolveCircle()` 处理圆与 AABB 碰撞
- 圆心在盒内时计算到四面墙外的距离，沿最短方向整段推出
- 多次迭代（3 次）提高稳定性

**贴图：base64 内嵌 + 程序化兜底**
- CC0 真实贴图（Poly Haven）下载后转 base64 data URL 内嵌
- 程序化 CanvasTexture 作为加载完成前的兜底，避免黑帧
- 离线零 CORS 风险

**材质：独立实例 + PMREM 环境反射**
- 每把武器使用独立 material 实例，避免变换互相污染
- `scene.environment` 用 PMREM 生成程序化室内光照，让金属有真实反射
- `MeshPhysicalMaterial` + clearcoat 提升涂层质感

**渲染防御：逐项 try/catch**
- WebGLRenderer 创建失败逐级降级
- shadowMap / colorSpace / toneMapping 各自 try/catch
- PMREM / TextureForge 失败静默降级

## 6. 游戏机制详述

### 6.1 回合流程

```
_beginRun() → _nextWave() → 生成 spawnQueue → _spawnFromQueue(2) →
主循环每帧 _update(dt) → 间隔刷怪 → 清场检测 → _nextWave() → ...
```

- 每局随机总波次数（8~12）
- 每波参数随机生成（人数/血量/速度浮动）
- 波次完成判定：spawnQueue 空 + 场上敌人 0 + 2s 延迟
- 玩家死亡 → `_endRun(false)` → 结算界面

### 6.2 波次参数生成

```js
count = baseCount + (wave-1) * countPerWave + jitter   // 3→14，封顶
hp     = hpBase + (wave-1) * hpPerWave + jitter        // 80→300，封顶
speed  = speedBase + (wave-1) * speedPerWave + jitter  // 2.8→4.8，封顶
tier   = wave > totalWaves * 0.45 → elite（人数×1.35，封顶 18）
         wave > totalWaves * 0.75 → ace（更强属性）
```

### 6.3 武器切换与弹药管理

- 三把武器各自独立状态（mag/reserve），切枪时 stash 保留
- 切枪冷却 = config.switchTime（USP 0.3s / AK 0.3s / AWP 0.5s）
- 切枪动画：下放（0~0.5）→ 上抬（0.5~1）
- 弹药包补给：当前枪 + 已 stash 过的枪都补，各自封顶在初始 reserve

### 6.4 射击流程

```
triggerSemi() / setFiring() → _fire() →
  1. 检查空仓 → dryFire + autoReload
  2. mag-- / fireCooldown = fireRate
  3. 连发散布累积
  4. 计算弹道方向（带散布 + 移动修正）
  5. applyRecoil() 后坐力
  6. _hitscan() 三角级求交
  7. map.raycastDetailed() 墙遮挡
  8. 视觉：tracer / muzzleFlash / shell
  9. 命中处理：伤害计算 / hitMarker / 伤害飘字 / 着弹火花 / 音效
```

### 6.5 敌人行为详述

```
每帧 update(dt):
  1. 倒地动画（deathTimer 2.0s，旋转倒下 + 下沉）
  2. 视线检测（0.12s 节流）→ canSeePlayer()
  3. 状态机：idle → react(0.35s) → engage
  4. engage 行为：
     - 卡墙强制逃离（0.8s，朝最开阔方向）
     - 冲刺突进（rushTime 0.8s，速度×2.2）
     - 距离策略：远距接近 / 中距绕圈 / 近距后撤或压近
     - 开火：seen + dist < fireRange + cooldown → _fireBurst
     - 点射间隔：burstLeft 发，每发间隔 burstDelay
     - 近战：贴身概率出拳
  5. AI-AI 防穿模（10Hz 节流）
  6. 腿部摆动 + 朝向更新
```

## 12. 附录

### 12.1 决策记录摘要

| 决策 | 选择 | 原因 |
|------|------|------|
| 命中判定 | 三角级 Raycaster | 命中贴合真实几何，部位分类精确 |
| 敌人命中网格 | clone 后设 userData | 避免 clone() 复制引用类型被破坏 |
| 墙命中 | raycastDetailed 返回 {t, normal} | 弹孔沿墙面法线贴合 |
| 武器贴图 | CC0 贴图 base64 内嵌 + 程序化兜底 | 离线可用、零 CORS 风险 |
| 随机多关卡 | 波次参数随机化 | 提升重玩性 |
| 敌人卡墙解困 | 朝最开阔方向逃离 | 反转横移在角落仍会撞墙 |
| Glock-18 程序化模型 | `weapon.js` 内部 `ExtrudeGeometry` 等几何构建 | 与 AK/AWP 的内嵌 OBJ 模型分工明确 |
| AK 贴图 | 程式化暖青铜军绿 diffuse | 避免 UV 展开图当 diffuse 的严重错误 |
| 护盾系统 | 敌人 18% 概率掉落 + 拾取补给 | 加护盾层让玩家有血/护甲双资源运营 |
| 武器模型拆分 | 独立模块（ak47_model 等） | weapon.js 已 91KB 臃肿 |
| 手感三件套 | 弹壳 + viewKick 后坐 + 枪口焰 | 三位一体反馈，缺任何一项都"塑料感" |
| 换弹动画 | 四段复合（卸夹→脱出→插夹→回位） | 单段僵硬，四段更接近真实 |
| 材质独立化 | 每把武器独立 material | 避免多枪同屏时变换串味 |

### 12.2 经验教训摘要

1. 命中求交要贴合真实网格（手写近似偏差大）
2. 命中发生在 render 前，矩阵需强制刷新
3. clone() 的 userData 复制不可靠
4. Raycaster.intersectObjects 已按距离排序
5. 离线贴图用程序化 CanvasTexture
6. 移动端 HUD 元素需 pointer-events:auto
7. 离线真实贴图：base64 内嵌 + 程序化兜底
8. Web 无法强制横屏，用竖屏提示引导
9. 圆-AABB 碰撞：圆心进盒后推力为零，必须按最浅穿透轴推出
10. J:\cs1.5 是旧副本，真实项目在 J:\个人IP打造\red\red-app\cs1.5
11. 移动端控件必须随内容尺寸缩放，禁止固定像素偏移
12. IAB 的 cua.drag 不派发"按下"
13. 指针锁定会劫持一切鼠标测试
14. #hud 内新面板必须显式 pointer-events:auto
15. Playwright 定位点击在 CSS 旋转视图中可能偏差
16. 旋转容器内做直接操控，屏幕坐标必须换算成内容坐标
17. 旋转容器内禁用 position:fixed，用 absolute
18. Poly Haven 贴图文件名不统一（diff vs diffuse）
19. 金属要真实必须加环境贴图（PMREM）
20. 旋转态方向错位：屏幕方向 ≠ 玩家移动方向
21. ExtrudeGeometry + Shape 做写实枪械轮廓
22. CSS 动画重启：void el.offsetWidth
23. 伤害飘字 DOM 池 + worldToScreen 投影
24. 满资源不消耗：保留补给在场上
25. 武器模型拆分独立模块
26. PowerShell 写 JS 触发 GBK 乱码 → 用 Node.js 统一 UTF-8
27. WorkBuddy safe-delete 钩子拦截打包 → env -u PYTHONPATH python zipfile 绕行
