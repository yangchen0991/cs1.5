# 一人不撤真机验收清单（GameFactory-3A 框架 review table 适配）

> 用途：当前版本候选包的真实设备验收标准。桌面浏览器、模拟移动档和用户已完成的小红书容器真机测试分开记录；未有逐项证据的结果保持未勾选。
> 版本：生涯击杀勋章候选（51 个文件，6,825,918 B，SHA256 `7D2D7066E20E596A88CBEBA66FC1628AC918FA79732F8C70708ED7E01C791E43`）；以 42 文件无双手真机确认版为恢复基线。
> 碰撞边界：港口视觉模型/PBR 与行走碰撞分离但由同一模型生成；运行时使用 138 个同模型栅格合并结构盒和 4 个外围边界盒，共 142 个移动 AABB，玩家和敌人移动按 4m 空间分区与不超过 0.2m 的 `moveCircle` 轨迹步长解算，敌人分离推力也走同一连续路径。玩家弹道、敌人弹道和敌人视线先对真实导入模型求交，窄墙漏检时使用同一模型派生阻挡层兜底，外围盒只作边缘兜底。旧 509 个自动代理和白色低矮体块已归档，环境地面与边界复用公共混凝土材质配置且不引用武器色彩。

> **当前执行状态（2026-08-30）**
>
> - **浏览器/模拟移动验证边界**：Chrome/Playwright 已检查勋章 0 击杀锁定态、25 击杀解锁态、非阻塞横幅、分享卡、返回链路及 390×844/844×390 布局，控制台无业务错误。10 个 Node 测试文件共 264 项通过，39 个 JavaScript 通过语法检查。
> - **用户确认的真机测试**：用户此前确认通过的是 42 文件无双手原始包；当前 51 文件勋章候选尚未上传并复测，所以下方全部新旧细项都不反推为已勾选。
> - **候选包边界**：当前 51 文件勋章候选已通过 `pwsh` 与 Windows PowerShell 5.1 精确校验；42 文件确认包保持原路径和哈希不变，双手与 AK 融合候选只保留为历史，不进入当前发布。

## 七、已知限制与复测边界

- 当前 51 文件候选只在 42 文件无双手真机确认基线上新增勋章状态、UI、分享适配和六张 WebP；双手、AK 融合握持、轴向修复与画质融合候选仍已退出活动运行时和发布清单。旧 42 文件真机结论不能替代当前候选复测。
- 当前港口行走碰撞是 138 个同模型栅格合并结构盒加 4 个外围边界，不等同于逐三角形移动物理；港口弹道和 AI 视线先使用真实模型三角面射线，再由同模型派生阻挡层兜底。修改模型或布局后必须复测出生点、开放通道、绕行、玩家/敌人射线和 AI 视线。4m 分区与不超过 0.2m 的轨迹步长只是运行时策略，不能替代设备观察。
- 卧倒会保留移动和射击；卧倒时第一次按「跳」先起身，站立后再次按「跳」才跳跃。触屏性能保护可能降低画面清晰度或关闭阴影，池化限制的是高频反馈瞬时数量，不保证每台设备固定帧率。
