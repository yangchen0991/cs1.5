# 一人不撤 — 离线 3D 触控生存射击

一款基于 **Three.js + 原生 JavaScript** 实现的第一人称射击游戏（FPS）单局 Demo，采用熟悉的竞技射击操作与回合推进体验。纯浏览器运行，无需安装任何依赖，可打包为小红书离线小工具 zip 发布。

> **当前文档同步状态（2026-08-30）**：当前源码加载港口离线视觉模型、包内 PBR 图片和同版本生成的 `map_collision.js`。移动层使用从视觉模型地面结构投影合并出的 138 个结构 AABB，加 4 个外围边界盒，共 142 个移动盒；港口弹道和敌人视线先对真实导入网格做 `THREE.Raycaster`，再用同一模型派生阻挡层兜底，避免窄墙漏检造成穿透。环境层通过 `environment_materials.js` 复用混凝土材质配置，且不读取任何武器色彩。旧模型代理、低矮白色体块和历史运行时脚本已移到 `archive/assets/maps/container-port/legacy-runtime/`，不进入当前活动碰撞层。
>
> 当前港口的移动碰撞和视觉模型来自同一份离线几何：构建期将 494 个模型结构盒写入 0.5m 栅格，再合并为 138 个行走盒，覆盖 4,811 个模型投影单元；悬空结构不压到地面，低矮装饰不会制造移动空气墙。子弹/敌人视线先以真实模型表面为准，模型简化面漏检时与玩家/敌人移动共用模型派生阻挡层，外围 4 盒仅作地图边缘兜底。首屏同步加载 9 个轻量经典脚本，其中 3 个负责勋章状态、界面和分享卡；六张勋章图只在打开勋章中心或分享卡时按需解码。点击开始后，`resource_loader.js` 才按所选地图和设备档加载地图、敌人、三枪与贴图，并在加载层内完成解码、地图构建和 GPU 预热。当前源码以用户确认的无双手 42 文件版本为恢复基线，增加生涯击杀勋章后形成独立 51 文件候选；仍不包含 `hands_*` 或 AK+双臂融合模型。

## ✨ 特性

- 📱 **移动端横屏 + 触屏操控**：容器竖屏时用 CSS 整页旋转；左摇杆移动、右半屏滑动视角、右侧 FIRE 拖动追枪、左侧独立 FIRE 三指开火，动作键按触点分工；设置中心使用原生滚动并为旋转 WebView 提供 Touch Events 手动滚动兜底，按钮布局、大小、转身灵敏度、准星样式和敌方伤害范围可保存到本机；虚拟控制层独立于 HUD，编辑态可直接拖动；设置关闭按进入来源返回游戏/暂停，触点丢失时统一释放摇杆和开火；提供「卧」按钮切换卧倒/起身
- 🎯 **第一人称射击**：桌面 Pointer Events 鼠标拖动视角，触屏支持 Pointer/Touch Events + 浮动摇杆 + WASD 语义移动 + 跳跃
- 🔫 **三把武器**：Glock-18 手枪（半自动，20 发弹匣）、AK-47（全自动）、AWP 狙击枪（栓动 + 瞄准镜开镜），各自独立的伤害/射速/后坐力/弹道散布/距离衰减/连发散布累积
- 🔨 **精细武器模型**：Glock-18 使用程序化模型；AK-47 与 AWP 使用由原 OBJ 离线量化生成的模型脚本和包内 PBR 图片，运行时不解析 OBJ
- 🎯 **完整命中反馈**：命中标记 X（白/爆头金放大/击杀红色更大更久）+ 伤害飘字（-24 / 爆头 -96）+ 部位倍率（爆头 4 倍、腿部 0.75 倍）+ 距离衰减（10m 满伤 → 50m 衰减至 50%）+ 连发散布累积（AK 越打越散，停止快速收拢）
- 🎯 **可选准星**：设置中可选择经典十字、点式、圆环、实心十字和战术十字点；命中/击杀红色 X 是独立的短时反馈，显示后自动清除，不是常驻准星
- 🔫 **武器手感**：后坐力数据驱动（子弹发射时枪口/视角向上抬，随后按武器速度回正；AK 慢恢复需压枪 / Glock-18 快恢复），静止时不自动抬枪；切枪、换弹、死亡结算统一清理开镜状态，另有切枪动画（下放→上抬）、切枪音、换弹音效、空仓咔嗒音和低弹量告警；三把当前武器共用离线程序化分层枪口火光
- 🔥 **离线枪口火光**：每把当前武器都使用白热内芯、定向火舌、加法混合光晕和桌面端短距离点光源的分层效果；透明加法混合、Canvas 生成，无外链资源
- 🤖 **混合骨骼敌人**：用户固定持枪 FBX 离线转换为 24 节共享骨架与双骨权重；八个代号复用，支持前进/后退/横移二维步态、移动中上身瞄准、射击后坐与枪口火光、受击/近战/死亡动作层，以及三档护甲、三档 LOD 和分段命中代理；出生点会做安全复核，卡入建筑后移到最近合法位置

- 🎁 **补给系统**：4 个血包（+50 HP）+ 4 个弹药包固定点位，拾取后 15s 重生，玩家弹药按当前武器补充；敌人也能抢弹药包补充备弹，满状态不消耗
- 🎵 **程序化音效**：Web Audio API 合成枪声/命中/爆头/击杀/受伤/换弹/切枪/通关音，无需音频文件

- 🏅 **生涯击杀勋章**：生涯击杀达到 25/100/300/750/1500/3000 时依次解锁六枚勋章；进度仅保存在本机，解锁提示不拦截战斗操作，勋章中心可反复生成 1080×1440 本地分享卡。小红书端能力只在用户点按后打开发布页或保存图片，不静默发布，也不把发布/审核结果写入战斗状态

## 🏗️ 架构说明

游戏采用**模块化单例 + 引用注入**架构，全部类挂 `window` 命名空间。`index.html` 首屏只同步加载：

```text
config.js → three.min.js → hud.js → audio.js → medal_system.js → medal_ui.js → medal_share.js → resource_loader.js → main.js
```

点击开始后，资源调度器以包内相对路径顺序加载 `math2d.js`、三枪资源、敌人资源和游戏系统；港口模型/碰撞/PBR 只在选择港口时加载，桌面档再追加 `forge.js` 与 `enemy_model_hd.js`。全部仍是经典脚本，不使用模块、网络、Worker、WASM 或动态执行。

- `main.js` 的 `Game` 类持有所有子系统，驱动统一的 `requestAnimationFrame` 循环
- `WeaponSystem` 在敌人确认死亡时只发出一次结构化击杀事件；`MedalSystem` 由该权威事件累计生涯击杀，存储失败时只退化为本局内存状态，不阻断射击或结算
- `Player` / `WeaponSystem` / `Enemy` / `PickupSystem` 各自实现 `update(dt)`，主循环按顺序调用
- `GameMap` 集中碰撞与射线查询；港口视觉由根目录 `map_model.js` + `map_assets.js` 离线加载，移动层由同版本模型生成的 `map_collision.js` 提供 138 个结构性盒，再加 4 个外围边界盒，共 142 个移动 AABB，按空间分区供 `moveCircle` 沿轨迹以不超过 0.2m 的步长解算；港口弹道和敌人视线先对真实导入模型求交，再用同一模型派生盒兜底，移动、敌我子弹和 AI 视线不会各自使用不同墙体规则
- `environment_materials.js` 只维护混凝土、港口 PBR 槽位、集装箱和边界的环境材质词汇；地面与边界复用混凝土配置，模型视觉与碰撞分离，历史自动代理和白色低矮体块不进入当前运行时，环境层不引用武器色彩
- 武器模块持有 `enemies` 数组引用，射击时用 `THREE.Raycaster` 对随骨骼运动的贴合分段命中网格求交，区分头、躯干、手臂、腿和枪
- 反馈调用单向：`WeaponSystem` 是唯一调用方，统一调 `hud.*`（视觉）与 `audio.*`（听觉），职责清晰
- 高频弹道、命中特效和弹壳使用有上限的对象池（当前约 24 条弹道、24 个弹孔、30 个命中火花、12 个弹壳）；触屏运行时按帧时间窗口保守降低 DPR，帧时间仍超预算时关闭实时阴影，保留核心玩法

武器模型分工保持明确：Glock-18 由 `weapon.js` 内的 `_buildGlock()` 程序化构建；AK-47 与 AWP 由构建期量化模型模块提供，真实接口为 `build(geometry, material)`，武器系统实际调用 `build(null, material)`。三把枪并非全部使用导入模型。

## 🎯 胜负条件

- **胜利**：清空全部随机波次（8~12 波）
- **失败**：玩家血量归零
- 护甲（护盾点数）吸收 50% 伤害，归零后全额扣血；敌人掉落的护甲可补充护盾

## 📝 已知限制

- 敌人寻路为简化直线 + 双侧绕行，非完整 A*；复杂地形走位可能不够聪明，但出生点会先做合法性复核，运行中持续卡墙会尝试移到最近安全点并清除速度
- 港口当前加载量化离线视觉模型和三张包内 PBR 图片（基础色、法线、打包金属/粗糙度）；移动层使用从同版本模型生成并栅格合并的 138 个结构盒与 4 个外围边界盒，按 4m 空间分区查询并沿轨迹以不超过 0.2m 分步解算；港口弹道和敌人视线先求交真实模型，再用模型派生阻挡层兜底，低矮白色装饰不成为移动碰撞盒。地面/边界复用环境混凝土材质配置，环境材质与武器色彩完全隔离；历史 OBJ/PBR 重建工具和自动代理只在 `archive/assets/maps/container-port/legacy-runtime/` 追溯
- 卧倒是独立于蹲伏的姿态：按 `Z` 或移动端「卧」切换，眼高和速度降低、仍可移动和射击；卧倒时第一次按「跳」先起身，站立后再次按「跳」才离地，姿态过渡采用平滑量，不能替代最新候选的真机手感验收
- 触屏性能保护会按帧时间下调 DPR，必要时关闭实时阴影，可能牺牲画面清晰度或阴影效果；池化只限制高频反馈的瞬时数量，不代表所有设备都能维持固定帧率
- 核心游戏无联网功能，保持单机 PVE；只有用户点击“晒到小红书”或“保存图片”后才调用容器本地端能力，普通浏览器没有端能力时只显示提示
- 无买枪经济系统（Demo 范围）
