## 2. 最新游戏内容

### 2.1 运行时结构

发布清单包含 47 个根目录文件；`index.html` 首屏只同步加载 6 个经典脚本，其余由 `resource_loader.js` 按所选地图和设备档分段加载：

1. 页面与样式：`index.html`、`style.css`
2. 首屏基础：`config.js`、`three.min.js`、`hud.js`、`audio.js`、`resource_loader.js`、`main.js`
3. 延迟基础与系统：`math2d.js`、`forge.js`（桌面）、`environment_materials.js`、`map.js`、`player.js`、`enemy.js`、`weapon.js`、`pickup.js`
4. 武器与双手资源：AK/AWP 原有模型与 PBR；新增 `hands_model.js`、`hands_tex.js`、`hands_albedo.webp`、`hands_normal.webp`、`hands_mr.webp`
5. 敌人资源：`enemy_model.js`（移动两档）、`enemy_model_hd.js`（桌面高模）、`enemy_rig.js`、`enemy_albedo.webp`、`enemy_normal.webp`、`enemy_orm.webp`
6. 港口视觉与碰撞：`map_model.js`、`map_collision.js`、`map_assets.js`、`port_base.webp`、`port_normal.webp`、`port_mr.webp`
7. 共享环境：`textures.js`、`env_brick.webp`、`env_concrete.jpg`、`env_crate_wood.webp`

### 2.2 当前玩法

- 单机离线 PVE，随机波次、敌人强度、补给和护盾掉落。
- 开局菜单和设置页提供两张已接入地图；开始后锁定当前地图，玩家阵亡后从结算返回开始菜单才重新开放选择，胜利重开继续使用原地图。
- Glock-18 使用程序化模型；AK-47 与 AWP 使用从原 OBJ 构建的量化模型脚本和包内 PBR 图片；港口视觉使用量化离线模型与包内 PBR 图片，行走碰撞由同版本模型筛选生成，低矮装饰不进入移动层。
- 玩家可用桌面 `Z` 或移动端「卧」切换卧倒；卧倒降低眼高和速度但仍可移动和射击，第一次按跳只恢复站姿，站立后再次按跳才离地。
- 敌人采用 24 节共享混合骨架、离线语义双骨权重、三档 LOD（50,008 / 17,990 / 3,999 三角面）、二维移动混合、上半身瞄准和射击/受击/近战/死亡动作层。
- 敌人使用有限弹药：18 发弹匣、54 发备弹，打空后经过 1.5 秒换弹；备弹归零时在 28m 内搜索活动弹药包，取得 36 发后再换弹。敌方普通射击最低/最高伤害可在设置调整，默认 6～12 点并限制到玩家最大生命值范围，爆头与精英加成独立计算；敌人出生和持续卡墙均有安全位置复核/恢复。
- 使用真实网格 `THREE.Raycaster` 命中和部位标签；墙体使用 `raycastDetailed`，敌人每次实际开火前也调用同一射线边界。
- 三把当前武器均使用离线程序化分层枪口火光（内芯、火舌、光晕、桌面短距离点光源），透明加法混合，不依赖外链；命中/击杀红色 X 是独立短时反馈，自动清除，不是常驻准星。
- HUD 包含血量、护盾、弹药、波次、小地图、击杀提示、伤害飘字和命中反馈；Web Audio 合成枪声、切枪、换弹、命中和敌人声音；弹道、命中特效、弹孔和弹壳使用有上限的对象池。
- 桌面使用键盘与 Pointer Events；移动端使用 CSS 横屏适配、`visualViewport` 逻辑尺寸同步、平板控件缩放、左浮动摇杆、右侧视角、左右 FIRE 和动作按钮，按触点 owner 分工，不依赖 Pointer Lock；暂停/设置入口位于动作簇左侧的中右区域。
- 静态地图网格冻结矩阵更新；触屏运行时按 120 帧滚动窗口记录 P50/P95/P99，超预算时单向降低 DPR，必要时关闭实时阴影；首屏不构造地图、敌人或三枪，点击开始后才在加载层内按需加载、解码、建图、编译并生成非低端 PMREM。

### 2.3 当前限制

- 用户确认此前候选包完成过小红书容器真机测试；本轮最新候选尚未重新上传，仓库尚未保存设备型号、系统/客户端版本、录屏和逐项结果，不能据此把包含地图选择锁定/解锁在内的真实设备验收矩阵全部判为通过。
- 固定持枪 FBX 是单一静态网格，无法提供精确手指、拉栓、独立弹匣拆装或完全独立武器动作。
- 敌人路径为轻量直线/绕行逻辑，不是完整 A*。
- 港口当前 142 个移动 AABB（138 个同模型栅格合并结构盒 + 4 个外围边界）是可审计的行走边界，不等同于逐三角形移动物理；港口弹道与敌人视线先使用真实导入模型三角面射线，再以同模型派生阻挡层兜底，旧模型代理已停用，地面与边界复用 `environment_materials.js` 的混凝土配置，环境层不引用武器色彩。调整港口排布后必须重新生成碰撞文件并检查行走盒、出生点、射线和真机长局表现。
- 卧倒状态第一次按跳只站起，不会直接离地；触屏性能保护可能降低 DPR 或关闭阴影，池化只限制高频效果的瞬时数量，不能保证每台设备固定帧率。
- 当前版本仍是单机 PVE，不包含联网、商城、皮肤或经济系统。
- 地图选择当前只开放港口和经典两张完整接入地图；运行中不支持热切换，新增地图必须同时提供出生点、视觉层、碰撞、射线和回归测试。

- `archive/assets/textures/`：不再参与当前环境贴图构建的 `metal.jpg`、`wood.jpg`、`usp.png`。
- `archive/tooling/legacy/`：一次性 AWP/AK/USP 图像分析、旧模型重建、旧贴图缩放、安装脚本和 Python 生成缓存。
- `archive/tooling/skill-copy/.skill/`：与当前 `.codex/` 重复的旧 `.skill/` 副本。
- `archive/tooling/plugins/plugins/`：不属于最新游戏运行时的内容生产和软件团队插件。
- `archive/verification/playwright-cli/.playwright-cli/`：Playwright CLI 过程日志和页面快照，不作为游戏运行输入。

`$RECYCLE.BIN` 是 Windows 系统回收站元数据，不属于项目内容，本次不移动、不改写。
