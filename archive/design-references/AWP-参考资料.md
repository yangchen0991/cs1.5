# AWP 狙击步枪 · 外观与部件拆解参考资料

> 来源：百度百科「AWP狙击步枪」词条（2025-09 更新，引用中国军网/枪炮世界/现代枪械等）
> 用途：CS1.5 游戏 AWP 3D 模型精细化参考
> 注意：现实 AWP（警用）**全黑涂装**；用户上传的 jimeng 设计图是**橄榄绿枪身 + 浅黄木枪托**（游戏/艺术化版本）——建模以用户设计图配色为准，结构参考现实拆解。

## 基本参数
- 全枪长 1124mm，枪管 610mm，装弹 10 发（双排钢质弹匣）
- 配套：光学瞄准镜、瞄准镜座、两脚架、5 弹匣、背带、清洁工具；可选折叠托、夜视镜、可调贴腮板

## 部件拆解（按建模顺序）

| 部件 | 细节 | 建模要点 |
|------|------|---------|
| 机匣 | 铝合金，底部与两侧较平，由弹匣座附近螺钉固定 | 长方形圆角主体 |
| 枪机 | 旋转后拉式；拉机柄周围**数条纵向铣槽**（防冰冻结，AW 标志性外观） | 拉机柄 + 机匣侧铣槽 |
| 闭锁 | 机头 3 闭锁凸笋，旋转 60° 闭锁 | 不可见（内部） |
| 枪管 | 不锈钢，**外观呈锥形（截锥形剖面）**，枪口直径 23mm，40mm 螺纹联机匣 | 锥形长枪管（前细后粗） |
| 枪托 | 高强度塑料/纤维增强尼龙，**分两节**（上下两片），8 螺钉固定，长度 318~356mm 可调（填充块） | 两节式枪托 + 接缝 |
| 橡胶托底板 | 枪托后部橡胶 | 深色底板 |
| 贴腮垫 | 可调式贴腮板（可选装） | 枪托上方隆起 |
| 两脚架 | 合金钢，可折叠调节，收缩 152mm / 展开 254mm，双头螺栓装框架前部 | 前部可折叠两脚架 |
| 瞄准镜座 | 整块铝合金加工 + 套环，装 MkⅡ 光学瞄准镜 | 一体式镜座 + 镜筒 |
| 弹匣 | 双排钢质 10 发 | 短弹匣 |
| 挡手板 | 框架底部弹匣座前活动挡手板（0~89mm 可调） | 扳机护圈前小挡板 |
| 背带环 | 5 处：3 下护木、2 枪托 | 小环细节（可省） |
| 击针保险 | 枪机套上 3 位置保险杆 | 机匣后侧小拨杆 |
| 准星/照门 | AWP 取消后备机械瞄具（仅瞄准镜） | 可省略准星照门 |

## 与当前模型差异（待升级点）
1. **枪管锥形**（现为等径圆柱）→ 改截锥形（枪口细、近机匣粗）
2. **拉机柄纵向铣槽**（AW 标志，现无）→ 拉机柄旁加数条细凹槽
3. **两节式枪托**（现一体）→ 枪托中部加接缝线/分色
4. **可调贴腮垫**（现有）✅
5. **前部两脚架**（现有）✅
6. **挡手板**（现无）→ 扳机护圈前加小挡板
7. **配色**：以用户设计图为准（深橄榄绿 0x3f4a3c + 浅黄木 0xdcbf9a）
